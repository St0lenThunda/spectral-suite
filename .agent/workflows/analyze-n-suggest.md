# Analyze & Suggest Workflow

1. **Scan**: Analyze the current codebase or specific files for efficiency, clarity, and adherence to best practices.
2. **Identify**: Look for:
   - Performance bottlenecks.
   - Code duplication or "smells".
   - Opportunities for better abstraction.
   - Security vulnerabilities.
   - Lack of documentation or type safety.
3. **Categorize**: Group suggestions into categories:
   - **🚀 Performance**: Speed and resource usage.
   - **📝 Maintainability**: Clarity, structure, and documentation.
   - **🛡️ Quality/Security**: Potential bugs or vulnerabilities.
4. **Prioritize**: For each suggestion, indicate:
   - **Severity**: Critical / High / Medium / Low.
   - **Effort**: High / Medium / Low.
   - **Impact**: High / Medium / Low.
5. **Suggest**: Provide concrete code examples or architectural changes to implement the improvements.
6. **Next Steps**: Ask the user which suggestions they would like to implement or explore further.
