# Brainstorm Workflow

1. **Understand**: Analyze the user's input to identify the core problem or requirement.
2. **Ideate**: Brainstorm 3-5 distinct approaches or solutions.
3. **Analyze**: For each approach, provide:
   - **Concept**: A brief description of the idea.
   - **Pros**: Advantages of this approach.
   - **Cons**: Disadvantages or risks.
   - **System Cost**: Estimated impact on performance, complexity, or maintenance (Low/Medium/High).
4. **Present**: Display the analysis in a structured markdown format.
5. **Decide**: Ask the user for feedback or if they wish to pursue one of the options.
