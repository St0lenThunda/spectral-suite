# /market — Spectral Suite Marketing Agent

## Overview
This workflow provides structured marketing guidance across 4 phases. When invoked, determine which phase the user needs help with, then follow the corresponding steps.

## Step 1: Identify the Phase
Ask the user which phase they're working on:

1. **Position** — Define who we are, who we serve, and why we're different
2. **Content** — Create marketing materials, posts, demos, and copy
3. **Launch** — Execute the go-to-market checklist
4. **Grow** — Expand reach, analyze metrics, iterate

If the user doesn't specify, ask: "Which phase are you working on? (Position / Content / Launch / Grow)"

---

## Phase: POSITION
Goal: Sharpen the value proposition, messaging, and competitive positioning.

1. Read the following vault docs for current context:
   - `05 - Distribution & Outreach/Positioning & Messaging.md`
   - `05 - Distribution & Outreach/Competitive Landscape.md`
   - `02 - Product/Feature Set.md`
   - `00 - Overview/Value Proposition.md`

2. Based on the user's question, provide structured output covering:
   - **Target Audience Segment**: Who exactly are we talking to?
   - **Pain Point**: What's their frustration?
   - **Our Solution**: How Spectral Suite solves it (be specific to features)
   - **Differentiator**: What competitors CAN'T do that we can
   - **Objection Handling**: Anticipated pushback and responses
   - **Tagline Options**: 3 tagline variations

3. Ask the user to review and refine. Update vault docs if they approve.

---

## Phase: CONTENT
Goal: Create marketing content — social posts, blog drafts, demo scripts, ad copy.

1. Read the following vault docs:
   - `05 - Distribution & Outreach/Content Calendar.md`
   - `05 - Distribution & Outreach/Landing Page Copy.md`
   - `05 - Distribution & Outreach/Community Playbook.md`
   - `01 - Brand & Identity/Brand Voice & Language.md`

2. Ask the user what type of content they need:
   - **Social Post** (Twitter/X, Reddit, LinkedIn)
   - **Blog Article** (outline or full draft)
   - **Demo Script** (video walkthrough script)
   - **Email** (outreach, newsletter, launch announcement)
   - **Ad Copy** (short-form paid promotion)

3. Generate the content following brand voice guidelines. For each piece:
   - **Hook**: The opening line that grabs attention
   - **Body**: The core message
   - **CTA**: What do we want the reader to do?
   - **Platform Notes**: Character limits, hashtags, formatting for the target platform

4. Present 2-3 variations and ask the user to pick or refine.

---

## Phase: LAUNCH
Goal: Execute the go-to-market plan step by step.

1. Read `05 - Distribution & Outreach/Launch Checklist.md`

2. Ask the user where they are in the checklist:
   - **Pre-Launch**: Landing page, social accounts, demo content, beta testers
   - **Launch Day**: Post schedule, ProductHunt submission, Reddit/HN posts
   - **Post-Launch**: Metrics review, feedback collection, iteration

3. For the current stage, provide:
   - **Next 3 Actions**: Concrete, specific tasks (not vague advice)
   - **Templates**: Ready-to-use copy for each action
   - **Timeline**: Suggested deadlines
   - **Blockers**: What might go wrong and how to handle it

4. Update the Launch Checklist with completed items.

---

## Phase: GROW
Goal: Analyze, iterate, and expand reach after launch.

1. Read:
   - `05 - Distribution & Outreach/Community Playbook.md`
   - `09 - Notes & Iteration/Project Status & Roadmap.md`
   - `06 - Pricing & Monetization/Revenue Model.md`

2. Ask the user what growth lever they want to pull:
   - **Community**: Build Discord, Reddit presence, YouTube channel
   - **Content**: SEO, blog strategy, tutorial series
   - **Partnerships**: Collaboration with educators, music schools, YouTubers
   - **Pricing**: Analyze conversion rates, adjust tiers, add upsells
   - **Product-Led Growth**: Features that drive organic adoption (sharing, embeds)

3. Provide a structured growth plan:
   - **30-Day Goal**: One specific, measurable outcome
   - **Weekly Actions**: 3-4 tasks per week
   - **Metrics to Track**: What numbers matter
   - **Tools**: Specific platforms and services to use

---

## General Rules
- Always read vault context BEFORE generating content
- Follow the brand voice in `01 - Brand & Identity/Brand Voice & Language.md`
- Use the competitive positioning from `05 - Distribution & Outreach/Competitive Landscape.md`
- When creating copy, remember: Spectral Suite is **proprietary** (not open-source)
- Pricing references should use the Vital-style tier model ($0 / ~$8mo / ~$20mo)
- Our chord database has **666K+ songs** (vs. Hooktheory's ~40K) — use this in messaging
- Key differentiators: **Tonnetz geometry, real-time synthesis, spectral visualization**
