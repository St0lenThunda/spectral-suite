# Onboard Workflow

1. **Scan**: Read `README.md`, `package.json` (or equivalent), and the top-level directory structure.
2. **Architecture**: Identify the core tech stack, mainentry points, and architectural patterns (e.g., MVC, Hooks, Serverless).
3. **Environment**: Check for `.env.example` or documentation on required secrets/services.
4. **Commands**: Identify key scripts for building, testing, and running the project.
5. **Briefing**: Generate a 1-page summary for the current AI session including:
   - Project Goal.
   - Core Tech Stack.
   - Key Modules/Files.
   - Current Priorities (based on TODOs or recent commits).
   - "How to contribute" summary.
