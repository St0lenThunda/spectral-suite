# Spectral Suite: Educational Lessons Overview

This document details all interactive educational lessons and modules available within the Spectral Suite tools.

### Interactive Tool Manuals & Subjects Covered

| Tool Module | Step | Lesson Title | User Task / Interaction | Physics & Harmonic Theory Covered |
| :--- | :--- | :--- | :--- | :--- |
| **Aura Tune** | 1 | Calibration | Sing or play a steady note into the mic. | Autocorrelation, fundamental frequency, pitch detection. |
| | 2 | The Aura | Watch the 'Aura' rings pulse as volume changes. | Amplitude, sonic energy, pitch control stability. |
| | 3 | History Map | Observe the line graph below the aura. | Pitch tracking over time in 'Cents', vibrato visualization. |
| **Chord Capture** | 1 | Harmonic Input | Strum a chord on a guitar or play keys. | Polyphonic Pitch Detection (identifying multiple frequencies). |
| | 2 | Voicing Analysis | Check the virtual fretboard for detected positions. | Chord 'Voicings', octave positions, sonic character. |
| | 3 | Transcription | Click a detected chord to save it to a session. | Chromatic scale mapping, raw frequency to musical notation. |
| **Chord Forge** | 1 | Structural Design | Select a 'Recipe' (Suffix) to change the chord. | Mathematical intervals, tension frequencies (7ths, 9ths). |
| | 2 | Harmonic Energy | Toggle 'Extensions' to expand the sound. | High frequency energy bands, complex shimmering harmonics. |
| | 3 | The Inversion | Change the 'Bass' note for a different perspective. | Sonic stability, inversion energy, lowest-frequency anchoring. |
| **Frequency Flow** | 1 | Spectral View | Look at the main magnitude spectrum. | Fast Fourier Transform (FFT), sine wave decomposition. |
| | 2 | The Waterfall | Observe the scrolling colors behind the graph. | Spectral history, time vs frequency vs amplitude (heat maps). |
| | 3 | Note Detection | Watch the 'Peak Note' HUD identify frequencies. | Dominant frequency peaks, mathematical note quantization. |
| **Harmonic Orbit**| 1 | Gravitational Pull | Play a note to pull rings toward the center. | Harmonic Centers, dissonance vs consonance, musical tension. |
| | 2 | The Orbit | Select chord types to see their orbital geometry. | Geometric relationships, Perfect 5ths vs Major 3rds symmetry. |
| | 3 | Syncopation | Adjust the speed to see how orbits respond. | Rhythmic density vs visual velocity, harmonic progression speed. |
| **Pocket Engine** | 1 | The Grid | Tap the grid to place rhythmic triggers. | Division of time, fractional measures (1/16th notes). |
| | 2 | Micro-Timing | Adjust 'Swing' to change the beat's feel. | Rhythmic displacement, humanizing mechanical grooves. |
| | 3 | Probability | Lower the 'Chance' slider on a specific step. | System entropy, random number generation, rhythmic evolution. |
| **Resonance Lab** | 1 | Discovery Phase | Tap an object repeatedly near the microphone. | Impulse Response, natural resonant frequencies, material vibration. |
| | 2 | Harmonic Mirroring| Press 'Start Mirror' to project frequency back. | Sympathetic Resonance, external energy injection. |
| | 3 | Fine-Tuning | Move the 'Fine Tune' slider by 0.1Hz increments. | Constructive/destructive interference, 'Beats', slow-motion phases. |
| | 4 | Stroboscopic | Turn on the 'Strobe' and lock it to the target. | Stroboscopic freezing, visual stationary illusions of fast vibration. |
| **Scale Sleuth** | 1 | Fingerprinting | Play a series of notes or a melody line. | Pitch Class Sets, capturing unique notes independent of octaves. |
| | 2 | Pattern Matching | Look at the 'Confidence Score' for various scales. | Algorithmic overlap, probability of scale identification. |
| | 3 | Key Center | Observe how the 'Root Note' changes over time. | 'Tonic' gravity, weight of frequency and duration in perception. |
| **Track Tracer** | 1 | Blueprint Analysis | Upload an audio file or record a live signal. | Forensic audio scanning, energy peaks, rhythmic cycle bursts. |
| | 2 | Segment Recognition| Review the 'Sections' for Verse/Chorus markers. | Abrupt spectral/rhythmic shifts signaling structural changes. |
| | 3 | BPM Detection | Verify the detected tempo in the HUD. | Autocorrelation of low-frequency bands (kick drums), periodic pulse. |
| **Pitch Stairway**<br>*(Bend Trainer)* | 1 | Set Your Anchor | Tap a fret to pick the bend origin note. | Locking target frequencies, relative pitch measurements. |
| | 2 | Choose Target | Select ½, Full, 1½, or 2 step bend targets. | Semitones, translating physical fret distance to frequency shifts. |
| | 3 | Climb Staircase | Bend string and watch the cursor climb. | Continuous micro-pitch tracking: `1200 × log₂(current / start)`. |
| | 4 | The Blues Zone | Bend slightly flat to hit ¼-bend markers. | Microtones, non-standard tuning spaces outside traditional keys. |
| **Melody Mirror** | 1 | Target Pattern | Press 'Start Game' and listen to the reference. | Pure tone synthesis, Web Audio oscillators, pitch internalization. |
| | 2 | Vocal Mirroring | Sing the target note back into the microphone. | Fundamental frequency extraction, absolute pitch class matching. |
| | 3 | Micro-Tuning | Watch the 'Too High' / 'Too Low' indicator needle. | Interference detection, Unison vs Dissonance distances. |
| | 4 | Memory Expansion | Match the sequence to reach higher levels. | Short-term auditory memory, physical vocal chord precision mapping. |
| **Tonnetz Lattice**| 1 | Harmonic Geometry | Click any node to build a triad shape. | Spatial Pitch mapping, axes of P5/M3/m3, chord shape triangles. |
| | 2 | Parallel (P) | Transform a Major chord to its minor twin. | Shifting the 3rd by one semitone. |
| | 3 | Leading-Tone (L)| Execute an L-transform on the lattice. | Root/Fifth swapping, minimal physical motion for chord changes. |
| | 4 | Relative (R) | Jump to the relative minor or Major. | Anchoring common frequencies while shifting the third. |
